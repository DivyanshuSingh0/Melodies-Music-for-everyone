🎵 Melodies: Music for Everyone
Melodies is a modern and minimal desktop music application UI designed in Figma. This interface concept focuses on providing a smooth, user-friendly experience for music lovers with intuitive navigation, stylish design, and responsive layouts.

🌟 Features
🎧 Clean and modern music player interface

📁 Sidebar navigation for playlists, albums, and favorites

🔍 Search functionality and song browsing design

💜 Now Playing screen with album art and playback controls

🌗 Dark-themed layout for a sleek, premium feel

🔧 Tools Used
Figma (Desktop UI Design)

Custom icons and gradients

Auto-layouts and components

📁 Preview
Screens include:

Splash Screen

Home / Dashboard

Music Player

Playlist View

Settings Page

📌 Note
This is a UI/UX design prototype created in Figma. It is not a functional application but a conceptual design meant for visual presentation and inspiration.
